# 弘泰科技官網｜HTC

弘泰科技官方網站暨電商平台開發專案。

## 專案定位
建立響應式品牌官網與電商平台，整合商品展示、購物車、訂單、第三方支付、電子發票、物流資訊與客戶服務功能。

## 核心模組
- 品牌首頁與動態視覺
- 商品分類與商品搜尋
- 商品詳細頁
- 購物車
- 結帳流程
- 第三方支付
- 電子發票
- 訂單管理
- 物流／寄送資訊
- 常用通訊軟體通知
- 客戶諮詢／意見表單
- 響應式 UI／UX
- 後台商品與訂單管理

## Development
本專案使用 GitHub 進行版本控制，並由 Cursor 協助網站架構、UI/UX 與功能開發。
